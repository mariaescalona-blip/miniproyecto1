# Frontend — MiniProyecto 1

## Stack
- React
- React Router
- LocalStorage (mock temporal)

---

## Instalación

npm install

---

## Ejecutar en desarrollo

npm run dev

---

## Rutas principales

- /crear → Crear actividad
- /hoy → Ver actividades
- /actividad/:id → Ver detalle

---

## Notas técnicas

Mientras no exista conexión real con el backend,
se utiliza localStorage como persistencia temporal.
