# Flujo de usuario

Rol responsable: UX Lead (Andres Chicaiza)

Flujo principal del sistema:

1. El usuario accede al sistema.
2. El sistema muestra la vista "Hoy".
3. El usuario puede visualizar sus actividades registradas.
4. El usuario puede presionar "Crear actividad".
5. El sistema muestra el formulario de registro.
6. El usuario registra una nueva actividad.
7. El sistema redirige nuevamente a la vista "Hoy".
8. La actividad aparece en la lista.

Objetivo del flujo:
Garantizar una experiencia simple y rápida para gestionar actividades académicas.
