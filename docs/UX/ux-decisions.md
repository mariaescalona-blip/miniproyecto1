# Decisiones UX

## Decisión 1

Botón "Crear Actividad" visible en la barra superior.

Motivo:
Permitir acceso rápido a la acción principal.

Resultado:
El usuario puede registrar tareas rápidamente.

---

## Decisión 2

Tarjetas para mostrar actividades.

Motivo:
Mejor lectura y jerarquía visual.

Resultado:
Las actividades se identifican fácilmente.

---

# Iteración UX

Hallazgo:
Usuarios no encontraban subtareas.

Cambio:
Se agregó botón "Ver detalle".

Verificación:
Usuarios pudieron acceder a subtareas fácilmente.
