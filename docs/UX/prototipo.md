# Prototipo UX — Vista Hoy

El prototipo inicial se diseñó con enfoque mobile-first.

Objetivo:
Permitir al usuario visualizar sus actividades del día y registrar nuevas.

Elementos principales:

- Vista "Hoy"
- Lista de actividades
- Estado (Pendiente / Completada)
- Botón para crear actividad

Flujo principal:

1. Usuario entra a la aplicación
2. Visualiza actividades
3. Presiona "Crear actividad"
4. Registra nueva tarea
5. Regresa a la vista Hoy
