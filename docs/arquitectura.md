# Arquitectura del sistema

El sistema está dividido en dos capas principales.

## Frontend
Tecnologías:

- React
- Vite
- React Router

Estructura:

components/
pages/
services/
data/
styles/

Funciones principales:

- Visualización de actividades
- Creación de tareas
- Navegación SPA

## Backend

Tecnología:

- Django REST Framework

Responsabilidad:

- Manejo de API
- Persistencia de datos

## Despliegue

Frontend desplegado en Vercel.

URL pública disponible para visualización del sistema.
